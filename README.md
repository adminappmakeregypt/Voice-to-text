# 🔊 تحويل النص إلى صوت (Text to Speech)

برنامج ويب بسيط يحوّل النص المكتوب إلى صوت، يدعم العربية والإنجليزية ولغات أخرى.
مبني بـ HTML و CSS و JavaScript فقط باستخدام Web Speech API — بدون مكتبات أو سيرفر.

## المميزات
- اختيار الصوت (الأصوات العربية تظهر أولاً)
- التحكم في السرعة وطبقة الصوت ومستوى الصوت
- تشغيل / إيقاف مؤقت / استكمال / إيقاف
- يدعم النصوص الطويلة (يقسّمها تلقائيًا)
- يحفظ آخر صوت اخترته
- متجاوب مع الموبايل

## التشغيل
افتح `index.html` في المتصفح (يفضّل Chrome أو Edge).

## النشر على GitHub Pages
1. ارفع الملفات على Repository جديد.
2. Settings ← Pages ← Source: `main` branch / root ← Save.
3. الرابط هيكون: `https://USERNAME.github.io/REPO-NAME/`

## ملاحظة
الأصوات المتاحة تعتمد على المتصفح ونظام التشغيل. Edge فيه أصوات عربية طبيعية ممتازة (مثل Salma و Shakir المصريين).
